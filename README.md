## Why compounding

一次能跑通，只是本金。  
**真正完成的工作，要给下一次留下利息。**

对话很会制造动量——光标在动、答案在出、分支在涨。  
但动量会蒸发。两周后，第十五次修正为什么发生，往往已经埋在前十四个版本之间。

我关心的是另一类输出：

| 留下什么 | 为什么会复利 |
| --- | --- |
| **契约** | 怎样才算完成——下次不用重猜目标 |
| **边界** | 权力可见、有限、可恢复——信任可以调节，而不是预支 |
| **证据** | 到底发生了什么——责任在行动之后仍然站得住 |
| **下一步** | 不确定性还在哪——诚实的起点，而不是虚假的总结 |

> 创造工作的界面，不应该成为唯一能够理解这份工作的地方。

这不是自我提升课里的「知识复利」。  
是工程里的：**痕迹、信任、判断——每一次认真留下的，都让下一次更便宜。**

## Operating principles

不是口号墙。是我做选择时反复用到的尺子。

```
01  清晰本身就是功能。
02  约束塑造作品的性格。
03  证据比自信活得更久。
04  好的完成，是给未来的本金。
05  边界让「有分寸的信任」成为可能。
```

英文侧同一套：

- *Clarity is a feature.*
- *Constraints give a tool its character.*
- *Evidence outlives confidence.*
- *A real finish is principal for the future.*
- *Boundaries make measured trust possible.*
